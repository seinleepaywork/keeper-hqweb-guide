# Paywork UX Guide (Simplify 1.0)

지투시그마(페이워크) 프론트엔드 UX/UI 가이드 — 공개판.

**→ https://seinleepaywork.github.io/paywork-ux-guide/**

## 무엇인가

소상공인 B2B 정산·운영 플랫폼 페이워크의 화면 설계 규격이다. 개발자와 AI 코딩
에이전트(Claude Code)가 추측 없이 같은 결과를 내도록 만든 문서다.

- **§0 작업 개시 규칙** — 언제 이 문서를 펴고, 어떤 순서로 따르는가
- **§1 공통 헌법** — 무중단 피드백 · 모달 인풋 금지 · 점진적 정보 노출 · 타이포/금융 수치 · 서피스
- **§2 레이아웃 패턴** — 대시보드·원장형 / 포커스 문서형, 두 가지 밀도만
- **§3 거래 문서 상태 머신** — Draft → Sent → Viewed → Signed → Paid → Reported
- **§4 의도적 차이 vs 정리 후보**
- **§5 금지 패턴** — 작성 단계에 넣어야 하는 방어 코드
- **§6 Claude Code 룰셋** — `CLAUDE.md` 에 붙여넣는 정본

## 공개판 안내

이 저장소는 **공개판**이다. 사내 사고 이력과 미확정 결정 사항은 제외했다.
전문은 사내 저장소에 있다.

## 기술

단일 HTML 파일이고 **외부 요청이 0건**이다. 서체는 Spoqa Han Sans Neo(SIL OFL 1.1)를
문서에 등장하는 글자만 서브셋해 파일에 내장했다(웨이트 400/500/700, 각 50KB).
`src` 에 `local()` 을 먼저 두므로 폰트가 설치된 환경은 전체 글리프를 쓴다.

라이트/다크 테마를 모두 지원한다.
